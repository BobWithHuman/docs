같은 개념은 모든 페이지에서 같은 용어로 씁니다. 그래프 노드처럼 영어 이름이 있는 개념은 본문에서 한국어 용어를 쓰고, 표나 코드에서는 영어 이름을 씁니다.

## 엔진

| 용어 | 뜻 |
|---|---|
| PDP | Policy Decision Point. 도구 호출이 실행되기 전에 통과, 차단, 묻기 중 하나로 판정하는 엔진입니다. 이 명세가 다루는 대상입니다. |
| PEP | Policy Enforcement Point. 판정을 실제로 집행하는 곳입니다. 내장 도구는 PreToolUse 훅에서, MCP 도구는 agentgateway의 ext_authz에서 막습니다. |
| Jev | 진술문 하나가 맞을 확률을 돌려주는 모델입니다. 글을 쓰지는 못하므로 할 일과 후보 하나를 넣은 예/아니오 질문만 맡깁니다. |
| 인과 구조 파악 계층 | Call Parser, Token Index, Provenance Tracer로 이뤄진 계층(Causal Structure Layer)입니다. 인과 그래프를 만들고 시작점을 찾습니다. |
| 인과 그래프 | 엔진이 쌓는 노드와 간선의 그래프입니다. 프로버넌스 그래프라고도 부릅니다. "데이터 플로우"는 이 설계가 피하려는 출처 중심의 관점을 가리키므로 쓰지 않습니다. |

## 그래프

| 용어 | 뜻 |
|---|---|
| 요청 (Request) | 사용자가 보낸 요청입니다. |
| 할 일 (Task) | 에이전트가 도구를 호출하기 직전에 화면에 쓴 할 일입니다. 호출과 시작점을 이어 주는 다리 역할을 합니다. |
| 호출 (Call) | 도구 호출입니다. |
| 문단 (Segment) | 에이전트가 읽은 글의 한 문단입니다. 도구 결과를 문단으로 나눠 만듭니다. |
| 요소 (Element) | 호출 인자의 (역할, 값) 한 쌍입니다. |
| 제어 의존, 데이터 의존, 구조 | 간선의 세 갈래입니다. 시작점을 찾을 때는 제어 의존 간선만 따라갑니다. 자세한 내용은 [Edges](/docs/spec/common-model/edges/)에 있습니다. |
| 할 일 없음 | 호출 직전에 연결할 할 일이 끝내 들어오지 않은 경우입니다. 이때는 호출을 부모 후보와 직접 짝지어 Jev에 묻습니다. |

## 시작점

| 용어 | 뜻 |
|---|---|
| 시작점 | 호출에서 제어 의존 간선을 따라 올라가다 멈춘 곳입니다. USER, DELEGATED, DOC, ERROR, SELF, UNRESOLVED 중 하나로 분류합니다. 분류는 [Provenance Record](/docs/spec/common-model/provenance-record/#시작점)에 있습니다. |
| 사슬 | 호출에서 시작점까지 따라 올라간 간선들입니다. |
| 기준 점수 | Jev 점수를 보고 간선을 연결할지 정하는 문턱입니다. 지금은 임시 값 0.5를 씁니다. |
| 함께 걸린 후보 | 기준 점수를 넘었지만 따라가지 않은 부모 후보입니다. 점수와 함께 기록하고 판정에 씁니다. |
| 맡긴 문서 | 사용자가 요청에서 가리킨 문서입니다. #12 같은 이슈, 붙여 넣은 글, 링크가 해당합니다. |
| 주제 | 맡긴 문서에서 사용자가 준 일로 보는 부분입니다. 출처마다 정해진 규칙으로 표시합니다. 규칙은 [Segment Analyzer](/docs/spec/segment-analyzer/)에 있습니다. |
| 시키는 문장 | 읽는 사람에게 어떤 행동을 하라고 하는 문장입니다. Segment Analyzer가 문단에 표시합니다. |
| 숨긴 글 | 원문에는 있지만 화면에는 드러나지 않는 글입니다. 원문과 화면에 보이는 모습을 비교해 찾습니다. |

## 값

| 용어 | 뜻 |
|---|---|
| 가져온 값, 새로 쓴 값 | 호출 인자의 값 중 어딘가에서 가져온 값과, 메일 본문이나 코드처럼 에이전트가 새로 쓴 값입니다. 새로 쓴 값은 검사하지 않습니다. 둘을 구분하는 기준은 아직 정하지 않았습니다. |
| 괜찮은 값, 끼워 넣은 값, 근거 없는 값 | 가져온 값을 확인한 결과입니다. 확인 규칙은 [Value Types](/docs/spec/common-model/value-types/)에 있습니다. |
| 바깥 영향 | 파일이나 설정을 바꾸거나, 무언가를 밖으로 보내거나, 실행하는 것입니다. 바깥 영향이 없는 호출은 기록만 하고 통과시킵니다. |
| 정규화 | 값과 글을 비교하기 전에 모든 입력에 똑같이 적용하는 변환입니다. 원본도 함께 보관합니다. 이번 명세에서 정한 초안입니다. |

## 세션

| 용어 | 뜻 |
|---|---|
| 세션, 턴, 묶음 | 이벤트를 묶는 단위입니다. 부모 후보를 고르는 범위를 정할 때 씁니다. 각 단위의 경계는 아직 정하지 않았습니다. 자세한 내용은 [Identifiers and Ordering](/docs/spec/common-model/identifiers-and-ordering/)에 있습니다. |
| CLEAN, EXPOSED | 세션 상태입니다. 시키는 문장으로 표시된 문단이 세션에 한 번이라도 들어오면 EXPOSED가 되고, 다시 CLEAN으로 돌아가지 않습니다. |
| Provenance Record | Provenance Tracer가 호출 하나마다 정리해서 Decision Module로 넘기는 기록입니다. |
