## 엔진

| 용어 | 뜻 | 상태 |
|---|---|---|
| PDP | 판정 엔진. 도구 호출이 실행되기 전에 통과, 차단, 묻기 가운데 하나로 판정한다. 이 명세가 다루는 대상이다. | 확정 |
| PEP | 판정을 실제로 집행하는 곳. 내장 도구는 PreToolUse 훅에서, MCP 도구는 agentgateway의 ext_authz에서 막는다. | 확정 |
| Jev | 진술문 하나가 맞을 확률을 돌려주는 모델. 글을 쓰지는 못하므로 할 일과 후보 하나를 끼운 예/아니오 질문만 맡긴다. | 확정 |
| 인과 구조 파악 계층 | Call Parser, Token Index, Provenance Tracer로 이뤄진 계층(Causal Structure Layer). 인과 그래프를 만들고 시작점을 찾는다. | 확정 |
| 인과 그래프 | 엔진이 쌓아 가는 노드와 간선의 그래프. 프로버넌스 그래프라고도 한다. "데이터 플로우"는 이 설계가 피하려는 출처 쪽을 가리키는 말이라 쓰지 않는다. | 확정 |

## 그래프

| 용어 | 뜻 | 상태 |
|---|---|---|
| 요청 (Request) | 사용자가 보낸 요청. | 확정 |
| 할 일 (Task) | 에이전트가 도구를 부르기 직전에 화면에 쓴 할 일. 호출과 그 시작점을 잇는 다리가 된다. | 확정 |
| 호출 (Call) | 도구 호출. | 확정 |
| 문단 (Segment) | 에이전트가 읽은 글의 한 문단. 도구 결과를 문단으로 나눠 만든다. | 확정 |
| 요소 (Element) | 호출 인자의 (역할, 값) 한 쌍. | 확정 |
| 제어 의존, 데이터 의존, 구조 | 간선의 세 갈래. 시작점을 찾을 때는 제어 의존 간선만 따라간다. 자세한 내용은 [Edges](/docs/spec/common-model/edges/)에 있다. | 확정 |
| 할 일 없음 | 호출 직전에 이을 할 일이 끝내 들어오지 않은 경우. 이때는 호출을 부모 후보와 직접 짝지어 묻는다. | 확정 |

## 시작점

| 용어 | 뜻 | 상태 |
|---|---|---|
| 시작점 | 호출에서 제어 의존 간선을 따라 올라가다 멈춘 곳. USER, DELEGATED, DOC, ERROR, SELF, UNRESOLVED 가운데 하나로 나눈다([Provenance Record](/docs/spec/common-model/provenance-record/)). | 확정 |
| 사슬 | 호출에서 시작점까지 따라 올라간 간선들. | 확정 |
| 기준 점수 | Jev 점수를 보고 간선을 이을지 정하는 문턱. 지금은 임시로 0.5를 쓴다. | 초안 |
| 함께 걸린 후보 | 기준 점수를 넘었지만 따라가지 않은 부모 후보. 점수와 함께 기록해 판정에 쓴다. | 확정 |
| 맡긴 문서 | 요청할 때 사용자가 가리킨 문서. #12 같은 이슈, 붙여 넣은 글, 링크가 여기에 든다. | 확정 |
| 주제 | 맡긴 문서에서 사용자가 준 일로 보는 부분. 출처마다 정해진 규칙으로 표시한다([Segment Analyzer](/docs/spec/segment-analyzer/)). | 확정 |
| 시키는 문장 | 읽는 사람에게 어떤 행동을 하라고 하는 문장. Segment Analyzer가 문단에 표시한다. | 확정 |
| 숨긴 글 | 원문과 화면에 보이는 모습을 비교해 가려낸, 화면에는 드러나지 않는 글. | 확정 |

## 값

| 용어 | 뜻 | 상태 |
|---|---|---|
| 가져온 값, 새로 쓴 값 | 호출 인자의 값 가운데 어딘가에서 가져온 값과, 메일 본문이나 코드처럼 에이전트가 새로 쓴 값. 새로 쓴 값은 따지지 않는다. 둘을 가르는 기준은 미정이다. | 확정 |
| 괜찮은 값, 끼워 넣은 값, 근거 없는 값 | 가져온 값을 확인한 결과([Value Types](/docs/spec/common-model/value-types/)). | 확정 |
| 바깥 영향 | 파일이나 설정을 바꾸거나, 무언가를 밖으로 보내거나, 실행하는 것. 바깥 영향이 없는 호출은 기록만 하고 통과시킨다. | 확정 |
| 정규화 | 값과 글을 비교하기 전에 모든 입력에 똑같이 적용하는 규칙. 원본은 함께 보관한다. | 초안 |

## 세션

| 용어 | 뜻 | 상태 |
|---|---|---|
| 세션, 턴, 묶음 | 이벤트를 묶는 단위. 부모 후보를 고르는 범위를 정할 때 쓴다. 각 단위의 경계를 어떻게 정하는지는 미정이다([Identifiers and Ordering](/docs/spec/common-model/identifiers-and-ordering/)). | 확정 |
| CLEAN, EXPOSED | 세션 상태. 시키는 문장으로 표시된 문단이 세션에 한 번이라도 들어오면 EXPOSED가 되고, 다시 CLEAN으로 돌아가지 않는다. | 확정 |
| Provenance Record | 호출 하나에 대해 Provenance Tracer가 정리해 Decision Module로 넘기는 기록. | 확정 |
