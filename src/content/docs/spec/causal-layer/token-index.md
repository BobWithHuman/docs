## 하는 일

Call Parser가 가른 가져온 값마다, 그 값이 앞서 관찰한 요청이나 문단에 글자 그대로 적혀 있는지 찾는다. Jev는 쓰지 않는다. 값을 통째로 찾아보고, 없으면 정규화한 뒤 다시 찾고, 그래도 없으면 조각 단위로 일치를 찾는다. (확정)

값이 여러 곳에 있으면 처음 나온 곳을 출처로 삼는다. 앞서 읽은 문서의 값이 도구 결과를 한 번 거쳐 출처가 세탁되는 것을 막기 위해서다. (확정)

정규화 규칙은 [Value Types](/docs/spec/common-model/value-types/#정규화)에 있다. (초안)

1차에는 통째로 찾기와 정규화 일치까지만 만든다. (확정)

## 받는 것

Call Parser가 만든 Element 가운데 가져온 값, 그리고 앞서 관찰한 Request와 Segment의 글을 받는다. (확정)

## 내놓는 것

값이 적힌 곳을 찾으면 Element에서 그 Request나 Segment로 value_from 간선을 만든다. 어디에서도 찾지 못하면 간선을 만들지 않고, 그 값은 "어디에도 글자 그대로 없음"으로 확인 단계에 넘어간다. 찾은 출처는 Provenance Record의 호출·요소 필드에 들어간다. (확정)

## Jev 질문

Token Index는 Jev에 묻지 않는다. (확정)

## 미정

조각 일치에서 어느 정도 길이의 조각부터 일치로 볼지 정하지 않았다. 정규화 규칙도 초안이라 어떤 값을 경로나 URL로 볼지, 규칙을 어떤 순서로 적용할지가 남아 있다.
